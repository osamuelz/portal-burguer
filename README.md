# 🍔 Portal Burguer - Landing Page

Um projeto de uma página web completa e interativa para uma hamburgueria artesanal. 

> 🔗 **[Acesse o projeto online aqui
](osamuelz.github.io/portal-burguer)**

## 📋 Sobre o Projeto

Este projeto foi desenvolvido para criar uma interface moderna e atrativa para um delivery de hambúrgueres. O site é responsivo (funciona bem em celulares e computadores) e possui um formulário de pedidos com cálculo automático de preços.

## ✨ Funcionalidades

- Exibição de cardápio com filtros por categorias (Bovinos, Vegetarianos, Porções).
- Carrinho de compras interativo que calcula o valor total em tempo real.
- Design responsivo para dispositivos móveis.
- Links para redes sociais.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido com as seguintes tecnologias:

- **HTML5:** Para a estrutura da página.
- **CSS3:** Para o visual, cores, animações e layout (utilizando Flexbox/Grid).
- **JavaScript:** Para a interatividade (filtros do cardápio e cálculo do carrinho).
